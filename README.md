# Remix of Skylight Showcase

You are a senior product designer, senior frontend architect, and award-winning creative agency web designer.

Generate a fully functional, enterprise-grade, production-ready website for a professional media production company.

Company Name: Skylight Media Solutions

Primary media reference and portfolio inspiration:
https://www.facebook.com/SkylightMediaSolutions

The Facebook page contains real client work, videos, and production projects. The website should be designed so that these videos and images can easily replace placeholders with minimal effort.

The final result must look like a $50,000–$100,000 premium creative agency website, comparable to the best global media production companies.

The website must require less than 5% customization after generation. The only expected changes should be replacing placeholder media with real content.

GLOBAL WEBSITE REQUIREMENTS

• Fully functional navigation
• All buttons operational
• Fully responsive (mobile, tablet, desktop)
• SEO optimized structure
• Ultra fast performance
• Production ready UI/UX
• Replaceable image and video placeholders
• Portfolio system ready for future uploads

Media placeholders must be real functional components, not static images.
